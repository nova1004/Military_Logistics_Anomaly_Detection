# Military Logistics Anomaly Detection Using Machine Learning

An academic ML minor project. It uses **Isolation Forest** (unsupervised) to flag
unusual shipment records in a **simulated** logistics dataset.

> All data is synthetic, generated by `generate_dataset.py`. Flagged records are
> statistical outliers only. They are **not** confirmed sabotage, threats or
> security breaches.

## Folder structure

```
Military_Logistics_Anomaly_Detection/
├── generate_dataset.py            creates the simulated data (fixed seed 42)
├── train_model.py                 preprocessing, Isolation Forest, outputs, graphs
├── shipment_data.csv              simulated dataset (800 records)
├── simulated_labels.csv           hidden generator tags, NOT used for training
├── shipment_anomaly_results.csv   all shipments + prediction + anomaly score
├── logistics_risk_report.csv      only flagged shipments
├── visualizations/                3 PNG graphs
└── report/                        academic report
```

## Setup

Python 3.9+ is enough.

```
pip install pandas numpy matplotlib scikit-learn
```

## Run

```
python generate_dataset.py
python train_model.py
```

Run both from inside this folder. Order matters: the first script creates the
CSV that the second reads.

## Reading the results

- `prediction`: `Anomaly` or `Normal` (scikit-learn gives -1 / +1, converted to words).
- `anomaly_score`: from `decision_function`. **Lower = more unusual.** Negative
  scores are flagged; the most negative are the strongest outliers.
- `contamination = 0.05` is an assumed share of anomalies, not a real-world rate.

## Common errors

| Error | Fix |
|-------|-----|
| `FileNotFoundError: shipment_data.csv` | Run `generate_dataset.py` first, from this folder |
| `ModuleNotFoundError` | `pip install pandas numpy matplotlib scikit-learn` |
| Different numbers than the report | Same seed and library versions give identical results; versions used: pandas 3.0.5, numpy 2.5.3, matplotlib 3.11.2, scikit-learn 1.9.1 |

## Evaluation note

There are no genuine labels, so accuracy/precision/recall are not reported as
performance claims. `train_model.py` prints an optional comparison against the
generator's simulated tags, which only shows how the model behaves on records
we deliberately made unusual.
